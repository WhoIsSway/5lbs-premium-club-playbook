01 / RESEARCH LOGIC

研究框架与决策原则

每个案例都要回答“为什么有效、投入什么、不要照搬什么”。

01 / POSITION

定位假设

以专业训练能力为核心，向训练前、中、后延伸评估、教练、恢复、营养、服务和社群；不是泛化豪华健身房。

02 / MEMBER VALUE

会员价值

评估会员是否更容易开始训练、持续参与、看到进步、恢复并形成长期关系。

03 / EVIDENCE

证据分层

区分已运营事实、官方宣布/规划、分析推断、身份待核实。品牌宣传不等于经营成效。

04 / DECISION

投资决策

每个模块在自建、合作、试点、暂缓之间做判断，并用使用率、训练质量、留存和会员反馈验证。

统一决策规则： 优先建设核心训练能力与人才；专业医疗/检测优先合作；恢复与附加服务先试点；昂贵且需求未验证的设施暂缓。
02 / GLOBAL ANCHORS

全球核心对标

固定深化 Equinox、Third Space、Life Time；关注它们的系统能力，不只看装修。

03 / CHINA REFERENCES

国内参考品牌

先核实具体品牌与门店，再将事实归档；SHARPN TURF 与 SHARPN MASS 分开研究。

04 / CASE LIBRARY

全球案例库

搜索、筛选并展开案例明细。来源链接、证据状态与投资判断随案例保存。

没有匹配的案例。可以调整筛选条件。
05 / INVESTMENT MAP

投入地图：自建、合作、试点、暂缓

先判断会员价值与能力归属，再讨论预算。以下为默认假设，需要结合门店条件验证。

BUILD / 01

优先自建

训练硬件与动线、教练招聘培训、训练编程、基础评估逻辑、更衣洗浴基本功、社群与赛事日历。

PARTNER / 02

专业合作

运动医学、临床服务、专项检测、专业营养与康复；由合格伙伴承担专业交付，明确边界与转介流程。

PILOT / 03

小规模试点

恢复服务、咖啡营养、会员休息/办公、家庭活动、专项跑者产品；先看使用率、复购与服务质量。

DEFER / 04

暂缓投入

大型泳池/球场、复杂湿区、昂贵但低频的 Wellness 科技、规模化儿童托管；除非场地与需求证据充分。

会员旅程：所有投入都回到使用场景

从首次到访到长期归属，检查服务是否真正连接起来。

07 / PRODUCT MODULES

产品与空间模块地图

覆盖已讨论的投资方向；各模块的优先级会随证据更新。
